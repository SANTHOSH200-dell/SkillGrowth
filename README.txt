SKILLGROWTH FULL PROJECT
========================
1. Install PostgreSQL.
2. Create database: skillgrowth_db
3. Copy backend/.env.example to backend/.env
4. Put your PostgreSQL password into DATABASE_URL.
5. Double-click START_SKILLGROWTH.bat
6. Open http://127.0.0.1:5500/index.html
Backend: http://127.0.0.1:8000
API Docs: http://127.0.0.1:8000/docs
Demo credentials: test@skillgrowth.com / Test12345
If the demo account does not exist, use Register once with those values.
Never put AI/API secrets in frontend JavaScript. Put future AI keys in backend/.env.
